# Dark Rivers

Standalone archival repository for Dark Rivers, an interactive exploration
of recorded river Q-value observations in Ireland.

- Live website: https://salmonofdoubt.github.io/demos/dark-rivers/
- Original source: https://github.com/salmonofdoubt/salmonofdoubt.github.io/tree/master/demos/dark-rivers
- Frozen source commit: c3ea61a893737f92cfcfcfabb69c2884f52431f1
- Snapshot file inventory and SHA-256 hashes: SNAPSHOT.json
- Documentation: demos/dark-rivers/README.md

The original website remains unchanged. This archival repository contains
only the 21 files required for the Dark Rivers v0.1.0 snapshot, including
EPA-derived generated observation data and the shared styles and scripts.

Run python3 -m http.server 8000 from the repository root, then visit
http://localhost:8000/demos/dark-rivers/ to inspect the snapshot locally.

manual Zenodo draft; that is NOT the DOI of this repository's automatic
GitHub-to-Zenodo archive. Use the actual new Zenodo DOI once assigned.
Third-party datasets and map assets retain their own provenance and licences.
